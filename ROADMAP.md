# Dot Clash AI — Feature Roadmap

Core rule: **keep the strategic Dots & Boxes mechanic; only change objective/reward.**
Ship one phase → measure retention / matches-per-day → then the next. Avoid feature creep.
Every feature must pass: *"Does it make the player say 'just one more game'?"*

Keep **Classic mode clean** — special boxes are optional / mode-specific so new players aren't overwhelmed.

## Phase 1 — Juice the board (low effort, instant hook) ⭐ START HERE
- 👑 **Crown Box** → capture triggers **Lucky Spin** (spin wheel already exists — highest ROI)
- 🎁 **Mystery Box** → random reward on capture (coins / avatar / XP / ~5% nothing)

## Phase 2 — Strategic depth (special boxes + power-ups)
- 💣 **Trap Box** (penalty: AI extra turn / -points) — "take it or leave it for AI?" tension
- ⚡ **Lightning Box** (extra move) · 🧲 **Magnet Box** (next completed box is yours)
- **Power-ups** bought with coins: 🧲 Magnet · ⏰ Freeze AI · 🛡 Shield (coin sink)

## Phase 3 — Collection Mode (new objective, same engine)
- Collect X emojis before AI: Fruit Rush 🍓 / Emoji Battle 😀 / Treasure Hunt 💰💎 (avoid 💣)
- **Daily Collection Mission** — same challenge for everyone + leaderboard (Wordle-style DAU driver)

## Phase 4 — Events + AI personality (emotional retention)
- 🧠 **AI Revenge Mode** — beat Hard AI → next-day notification "rematch? 😈", AI avatar/dialogue changes
- ⭐ **Golden Week** (every Sunday: golden boxes, double coins, limited theme, leaderboard reset)
- Seasonal themes

## Phase 5 — Competitive endgame (high effort, needs user base)
- Ranked Seasons · Tournaments · Color War (competitive variant)

## Gold (must-do) vs Careful (later)
- **Gold:** Crown Box→Spin · AI Revenge Mode · Daily Collection Mission
- **Careful:** Tournaments (not too early) · too many special-box types introduced at once
